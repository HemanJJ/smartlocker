# 📦 販售庫存 使用教材

> 對象：館長／櫃台員工。用大白話寫，照著做就會。
> 系統位置：後台首頁 → **📦 販售庫存**（`/admin/inventory`）

## 一、這個模組在管什麼

管**無人店在賣的東西**（羽球、握把布、泡麵…）的完整循環：

> 進貨 → 上架 → 販售 → 盤點 → 補貨

系統會自動算庫存，庫存太低還會 **LINE 通知你補貨**。

---

## 二、先背這幾個名詞（欄位）

| 欄位 | 白話 | 範例 |
|------|------|------|
| SKU | 商品編號（唯一、不可重複） | `DEFI-BALL-12` |
| 名稱 | 商品名 | 迪飛比賽球（12入） |
| 分類 | `badminton` 羽球用品 / `ramen` 泡麵 / `other` 其他 | `badminton` |
| 售價 price | 賣給客人的價 | 300 |
| 進價 costPrice | 你進貨的成本 | 200 |
| 庫存 qty | 現在剩幾個 | 48 |
| 安全存量 minQty | 低於這數字 → LINE 提醒補貨（填 0 = 不提醒） | 20 |
| 狀態 | 上架中（客人看得到）／下架（客人看不到） | 上架中 |

---

## 三、從哪進去

後台首頁 → **📦 販售庫存**。

同一頁上方有分頁：**穿線 / 庫存 / 配貨 / 進貨 / 盤點 / 報表 / 供應商**。
右上角可**切換分店**（每個分店的庫存是分開算的）。

---

## 四、第一次開店：建基本資料（照順序做 3 件事）

### 第 1 步：建供應商（一定要先做）

進「供應商」頁 → 填名稱（例：羽球批發王）＋電話／備註 → 存。

> 進貨單要選供應商，所以供應商要先建好。

### 第 2 步：建商品（三種方式，選最快的那種）

- ✅ **最快（推薦）：用「進貨單」自動建檔**
  你根本不用一筆筆手 key 商品。開進貨單 → 選供應商 → 填商品＋數量＋進價 → **收貨入庫**，商品就會自動出現在庫存（見「五、進貨」）。
- **次快：配貨核准**——多店時，配貨核准後目的店會自動有這商品。
- **最慢但適合補單品**：庫存頁下方「＋ 新增」→ 填 SKU／名稱／分類／售價／數量 → 新增。

### 第 3 步（可選）：設「量價階梯」＝批發折扣

庫存頁最上方「🏷️ 量價階梯」：

- 例：滿 50 件 → 8 折、滿 100 件 → 7 折。
- 可套 **單一商品／整個分類／全部商品**，批次設定一次搞定。

## 五、日常標準流程

### ① 進貨（最常用）

進貨頁 → 「＋進貨單」→ 選供應商＋商品＋數量＋進價 → 存（狀態＝草稿）→ 貨到後按「**收貨入庫**」→ 庫存自動 ＋數量、更新成本、狀態變已入庫。

### ② 配貨到店（多店才用）

配貨頁 → 選「從哪店 → 到哪店」＋商品＋數量 → 存（草稿）→ 按「**核准**」→ 才真正**扣來源、加目的**，並 LINE 通知完成配送。

### ③ 販售（自動，不用你管）

客人從販賣機／無人店購買 → 系統自動扣庫存。

### ④ 盤點（定期，建議每週一次）

盤點頁 → 實際數每個商品 → 輸入「實際數量」→ 存 → 系統把庫存校正成實際值。

### ⑤ 補貨提醒（自動）

任何商品 **庫存 ≤ 安全存量** → LINE 自動推播給老闆（剩幾個、安全幾個），並提醒去後台開進貨單。

### ⑥ 看報表

報表頁一次看：**庫存總值、潛在利潤、低庫存清單、14 天內快過期清單**。

---

## 六、快速建檔三大撇步（總結）

1. **進貨單收貨＝自動建商品**：最省事，新商品第一次進貨順手就把檔建好。
2. **量價階梯「批次套用」**：一次設整類／全部的折扣，不用逐個 key。
3. **SKU 命名要有規則**（例 `DEFI-BALL-12`、`RAMEN-XXL`），以後好找、好盤點。

---

## 七、常見問題

- **商品下架 vs 刪除**：沒有「刪除」——把狀態改成「下架」就好，歷史記錄不會消失。
- **為什麼庫存對不上**：多半是漏按「收貨入庫」或漏盤點。進貨單記得要按收貨，才算真的入庫。
- **切錯分店**：每頁右上角的分店要選對，進貨／盤點／配貨都是「以分店為單位」。
- **安全存量填 0**：代表這商品不啟動低庫存提醒。

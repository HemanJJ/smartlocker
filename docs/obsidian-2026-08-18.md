## 踩坑記錄

1. **LINE Channel Access Token 生命週期**
   - 每次按 Reissue → 舊 token 立即失效
   - Vercel 上的 token 必須同步更新，否則 Webhook 401
   - 解法：沒事不要按 Reissue；按了就要更新 Vercel env

2. **@line/bot-sdk v11 與 Vercel Edge 不相容**
   - 換成 raw fetch 直接呼叫 LINE API 解決

3. **Vercel env 寫入特殊字元**
   - token 含 `+` `/` `=` 時，command line 直接傳會被 shell 解釋
   - 解法：`printf '%s' 'token...' > /tmp/t && vercel env add ... < /tmp/t`

4. **ngrok 不再需要**
   - LINE Developers Webhook URL 改成 `https://smartlocker-alpha.vercel.app/api/webhook`
   - LIFF Endpoint 改成同一網域

## 快速指令

```bash
# 部署
cd web && npx vercel --prod

# 資料庫初始化（僅首次）
cd web && node scripts/init-db.mjs

# 更新 LINE token
echo -n '新token...' > /tmp/t
cd web && npx vercel env rm LINE_CHANNEL_ACCESS_TOKEN production --yes
npx vercel env add LINE_CHANNEL_ACCESS_TOKEN production < /tmp/t
npx vercel --prod
```
